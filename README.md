# cs-roster

Formula-driven Excel roster planner for German teams (`Dienstplan.xlsx`,
generated by `make_roster.py`).

- Sheets: **Konfiguration** (year, FO strength, employees + Bundesland),
  Feiertage, Urlaub, Calc (hidden engine), **Dienstplan**, Auswertung
- **Dienstplan layout**: one row per employee, one column per working day
  (the day's date as the column header, row 1); auto-filter dropdowns on
  the header, same colors as before (FO blue, BO green, frei grey, Urlaub
  yellow, holiday red); alternate weeks shaded in the header row; unused
  employee rows are hidden by a pre-applied filter
- Configurable front-office strength (`Konfiguration!E4`, 1-8): each week
  the next group of K employees takes the FO block (Friday start, Mon-Thu
  next week, following Friday off for the whole group)
- Holidays: all German public holidays per Bundesland, computed from the
  year cell, plus 24.12. (Heiligabend) and 31.12. (Silvester) as company
  days off for all states
- Vacation: periods per employee on the `Urlaub` sheet (multiple rows per
  person allowed); FO shifts to the next available person, and nobody works
  two FO weeks in a row. The off-Friday requires FO on all four Mon-Thu days
- Future-proof: change only the year in `Konfiguration!B3`
