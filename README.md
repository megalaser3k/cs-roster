# cs-roster

Formula-driven Excel roster planner for German teams (`Dienstplan.xlsx`,
generated by `make_roster.py`).

- Arbitrary number of employees (up to 60); front-office rotates every N weeks
  (N = headcount): Friday start, Mon-Thu of the following week, next Friday off
- Mon-Fri working days; per-Bundesland German public holidays computed from a
  single year cell (future-proof: change `Config!B3` to roll over the year)
- Roster sheet is an Excel table (filter via header row) with conditional
  formatting: FO blue, BO green, frei grey, Urlaub yellow, holiday red
- Vacation: enter periods per employee on the `Urlaub` sheet; the roster
  updates dynamically (`Urlaub` overrides FO/BO/frei/holiday)
- Sheets: Config, Feiertage, Urlaub, Roster, Auswertung (per-employee hours)
